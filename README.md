# Numen Calculator for Flow Launcher

Natural-language calculator plugin for Flow Launcher, powered by [Numen](https://github.com/vicinaehq/numen).

## Build

Requires Windows x64, .NET 9 SDK, CMake 3.21+, and Visual Studio 2022 with the C++ workload.

```powershell
git clone --recursive https://github.com/MaxHasBeenUsed/Flow.Launcher.Plugin.NumenCalculator.git
cd Flow.Launcher.Plugin.NumenCalculator
.\build.ps1
.\install.ps1
```

Restart Flow Launcher after installing.
